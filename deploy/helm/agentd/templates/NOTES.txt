agentd {{ .Chart.AppVersion }} is installed.

1. Admin token (for the console and the agentserver CLI):
   kubectl -n {{ .Release.Namespace }} get secret {{ include "agentd.serverSecret" . }} -o jsonpath='{.data.admin-token}' | base64 -d; echo

2. Console and admin API (keep them private):
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "agentd.serverSvc" . }} 7800:{{ .Values.agentserver.service.adminPort }}
   open http://127.0.0.1:7800  (CLI: AGENTSERVER_ADMIN_URL=http://127.0.0.1:7800 AGENTSERVER_ADMIN_TOKEN=… agentserver status)

3. Relays register themselves with the bootstrap token. Point DNS at each relay Service:
{{- range .Values.relays }}
   {{ .domain }} -> kubectl -n {{ $.Release.Namespace }} get svc {{ include "agentd.fullname" $ }}-{{ .name }}
{{- end }}

4. Create a workspace and a join link, then join from each machine:
   agentserver workspace create home --relay {{ (index .Values.relays 0).name }}
   agentserver token create -w home --name laptop
   agentd join '<link>'
{{- if eq (index .Values.relays 0).tls.mode "selfsigned" }}

Relays use certificates from the chart CA (tls.mode selfsigned). Nodes trust it with:
   kubectl -n {{ .Release.Namespace }} get secret {{ include "agentd.fullname" . }}-agentserver-tls -o jsonpath='{.data.ca\.crt}' | base64 -d > agentd-ca.pem
   export AGENTD_EXTRA_ROOTS=$PWD/agentd-ca.pem
Use tls.mode acme or file for production.
{{- end }}
{{- if eq .Values.agentserver.defaultDnsProvider "selfsigned" }}

selfsigned); configure a Cloudflare dnsProviders entry for publicly trusted wildcards.
{{- end }}
